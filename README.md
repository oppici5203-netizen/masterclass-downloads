# Masterclass para Android

> **Descarga en preparación:** los instaladores todavía no están publicados. Los enlaces se activarán al terminar la versión 1.5.0 en Releases.

App nativa de Masterclass F.C. para los partidos, las fotos y las juntas del grupo.

## Instalación

Abre uno de estos enlaces desde el teléfono:

- **Primera instalación:** [Descargar Masterclass para Android](https://github.com/oppici5203-netizen/masterclass-downloads/releases/latest/download/Masterclass-Android.apk).
- **Si ya tienes una versión de prueba 1.4 o anterior:** [Descargar el actualizador](https://github.com/oppici5203-netizen/masterclass-downloads/releases/latest/download/Masterclass-Actualizar.apk). Instálalo, ábrelo y toca **Descargar Masterclass**; después instala el principal encima.

Android puede pedir permiso al navegador para instalar el archivo. No necesita Chrome ni el PC para usar la app instalada. [Ver archivos y notas de la última versión](https://github.com/oppici5203-netizen/masterclass-downloads/releases/latest).

Requiere Android9 o posterior y un teléfono ARM de64bits. Las bibliotecas x86_64 se incluyen para las pruebas en emulador. Versión preparada:1.5.0, código7. La instalación en un teléfono físico aún debe comprobarse.

Si tenías una versión de prueba1.4 o anterior, instala primero **Masterclass-Actualizar.apk**, ábrela y toca **Descargar Masterclass**. Después instala el APK principal encima. Este paso retira un permiso de la firma antigua sin borrar los datos. Para una instalación nueva usa directamente Masterclass-Android.apk. Las siguientes actualizaciones usan la firma propia.

No desinstales la app para resolver un error. Si Android rechaza la actualización, conserva el mensaje y la versión instalada para revisarlo.

## Grupo privado

La descarga del instalador no da acceso al grupo. Cada amigo entra por invitación; las fotos y los datos del grupo requieren su cuenta y permisos. La demo está identificada y no se publica automáticamente en el grupo.

La sincronización requiere internet en el teléfono. No exige la misma Wi-Fi que otro miembro ni mantener encendido un PC.

## iPhone

La instalación independiente sigue pendiente de firma Apple y prueba en iPhone. Este repositorio no ofrece una IPA ni anuncia TestFlight disponible. Expo Go es una vista previa distinta de una instalación propia.
